# Couple App 💕

Unsere gemeinsame PWA für Alltag, Nachrichten und Erinnerungen.

## Starten
```bash
npm install
npm run dev
```
Dann im Browser http://localhost:5173 öffnen.

Auf dem iPhone ansehen (gleiches WLAN): `npm run dev:handy` und die angezeigte `Network`-Adresse in Safari öffnen.
Installieren („Zum Home-Bildschirm") und Push funktionieren erst, wenn die App über HTTPS online ist (Schritt 4 im Fahrplan).

Mehr zu Plan und Aufbau: siehe `CLAUDE.md`.
